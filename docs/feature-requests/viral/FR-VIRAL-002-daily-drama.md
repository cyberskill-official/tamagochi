## §1 — Description (BCP-14 normative)

§1.1  **Drama definition.** A procedural micro-event in the player's pet life, e.g. "Mochi tried to eat your homework!", "Bao got stuck in a flower pot", "Tako painted the wall". Each is a 6-second animated vignette.

§1.2  **Trigger cadence.** Per pet, 1 drama eligibility per day. Eligibility resets at player's local midnight. Player can claim the drama whenever they next open the app; expires after 48 hours unclaimed.

§1.3  **Drama templates.** 30+ templates at launch, designer-curated, in `drama-templates.ts`. Templates parameterized by: pet species, current stage, current dominant stat trend (which stat is lowest), care-action history, time of day.

§1.4  **Selection logic.** Server selects template based on pet state + a deterministic seed (`SHA256(pet_id + local_date)`) to ensure repeatability + variety. Per FR-LEGAL-002 deterministic-only randomisation.

§1.5  **LLM-personalised dialogue (standard SKU).** Per FR-AI-001, the drama's "punchline" is generated by Claude Haiku based on the template + pet persona + last 20 events. Kids SKU uses scripted template-bank fallback per FR-AI-002.

§1.6  **6-second auto-render.** A 6-second Cocos scene renders the drama with Spine animation + Lottie overlays + caption text. The scene MUST be captureable via FR-VIRAL-001 export.

§1.7  **Share intent.** After drama plays, player sees "Share this moment?" CTA. Tapping invokes FR-VIRAL-001 share intent with prefilled caption + hashtag `#mochilife #dailydrama`.

§1.8  **Kids SKU share disabled.** Per FR-LEGAL-003 + FR-AUTH-003, share button hidden on kids SKU.

§1.9  **Drama types — 5 categories.** `mischief`, `cute`, `sad`, `excited`, `confused`. Each category has 6+ templates. Selection weighted by pet's current stat profile (e.g. low happiness biases towards `sad` or `confused`).

§1.10  **No drama in `grandma_house` or `egg`.** Stage-gated per FR-PET-002 §1.6.

§1.11  **Endpoint — claim.** `GET /v1/pets/:petId/daily-drama` returns the day's pending drama (template + LLM punchline + animation hints) or 204 if already claimed today.

§1.12  **Endpoint — share.** Returns the rendered share-clip URI for FR-VIRAL-001.

§1.13  **AI cost cap.** Per FR-AI-001 §1.9, LLM calls subject to 30/pet/day cap. Daily Drama counts against this; falls back to scripted on cap.

§1.14  **Audit.** `viral.daily_drama.shown { pet_id, template_id, llm_used: bool }`, `viral.daily_drama.shared { pet_id, share_link_id }` per FR-OBS-001.

§1.15  **Content safety.** LLM punchline passes through FR-AI-002 before delivery. Failure → scripted fallback.

§1.16  **DPO-reviewed template bank.** All scripted dramas + LLM prompt templates DPO-reviewed for kid-appropriateness + cultural sensitivity. Per FR-AI-002 §1.18.

§1.17  **Localisation.** EN + VI templates at P1+P2 launch. Other locales per FR-I18N-001 (P4).

§1.18  **Co-parent visibility.** If pet has co-parent (FR-SOCIAL-002), both see the drama. Either can be the "shared from" attribution.

§1.19  **Tenant-aware.** Drama templates can vary by tenant — B2B tenants (FR-B2B-001) override via tenant-themed template bundle.

§1.20  **Analytics — k-factor.** Drama share emits `viral.drama.share.invoked` per FR-VIRAL-001; share-link click tracking feeds the k-factor metric.

## §2 — Why this design

**Why daily cap.** Plan §PART 3 — too many dramas would saturate; once-per-day creates anticipation.

**Why 30+ templates.** Variety prevents "same drama again" feel within first 30 days of engagement.

**Why deterministic seed.** FR-LEGAL-002 §1.6 — auditable + repeatable for support tickets.

**Why LLM punchline.** Plan §PART 3 viral #3 — AI personality is the unfair advantage. LLM punchline makes each player's drama unique.

**Why kids SKU scripted only.** FR-AI-002 + COPPA — LLM-generated text to under-13 is regulator-toxic.

**Why 6-second clip.** TikTok-native attention budget + FR-VIRAL-001 default.

**Why 5 categories.** Cover the emotional spectrum without granularity overwhelm.

**Why stat-profile-weighted selection.** Plan §PART 3 — drama feels reactive to player's actual care.

**Why DPO-reviewed templates.** Kids audience + cultural sensitivity. Designer + DPO collaboration.

## §3 — API contract & code shape

```typescript
// apps/api/src/viral/daily-drama/daily-drama.service.ts
@Injectable()
export class DailyDramaService {
  async claimTodayDrama(u: AuthedUser, petId: string) {
    const pet = await this.pets.byId(petId);
    if (pet.owner_id !== u.id && !await this.coparent.is(petId, u.id)) throw new HttpException('forbidden', 403);
    if (!['baby','teen','adult'].includes(pet.stage)) throw new HttpException('pet.stage.locked', 422);
    const today = todayInUserRegion(u.id);
    const existing = await this.supa.from('daily_dramas').select('*').eq('pet_id', petId).eq('drama_date', today).maybeSingle();
    if (existing.data) {
      if (existing.data.claimed) return null;
      return this.renderResponse(existing.data);
    }
    const seed = sha256(`${petId}:${today}`).digest();
    const template = this.selectTemplate(pet, seed);
    let punchline: string;
    let llmUsed = false;
    if (await this.aiSku(u) === '13+') {
      try {
        const r = await this.ai.speak(petId, 'after_care', { context_overrides: { drama_template_id: template.id } });
        punchline = r.text;
        llmUsed = true;
      } catch {
        punchline = template.scripted_punchline;
      }
    } else {
      punchline = template.scripted_punchline;
    }
    const { data: row } = await this.supa.from('daily_dramas').insert({
      pet_id: petId, owner_id: u.id, drama_date: today,
      template_id: template.id, punchline, llm_used: llmUsed,
      expires_at: new Date(Date.now() + 48*3600*1000).toISOString(),
    }).select().single();
    return this.renderResponse(row);
  }

  private selectTemplate(pet: Pet, seed: Buffer): DramaTemplate {
    const lowestStat = ['hunger','cleanliness','happiness','energy'].sort((a, b) => pet[a] - pet[b])[0];
    const category = lowestStat === 'happiness' ? 'sad' : lowestStat === 'energy' ? 'confused' : 'mischief';
    const candidates = DRAMA_TEMPLATES.filter(t => t.category === category);
    return candidates[seed[0] % candidates.length];
  }
}
```

```sql
create table public.daily_dramas (
  id bigserial primary key,
  pet_id text not null references public.pets(id) on delete cascade,
  owner_id uuid not null,
  drama_date date not null,
  template_id text not null,
  punchline text not null,
  llm_used boolean not null default false,
  claimed boolean not null default false,
  claimed_at timestamptz,
  shared boolean not null default false,
  share_link_id text,
  expires_at timestamptz not null,
  tenant_id text not null default 'mochi',
  created_at timestamptz not null default now(),
  unique (pet_id, drama_date)
);
alter table public.daily_dramas enable row level security;
create policy "drama self" on public.daily_dramas for select using (owner_id = auth.uid());
```
